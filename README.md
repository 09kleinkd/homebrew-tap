# Homebrew tap

```sh
brew install --cask 09kleinkd/tap/bassjump-revived
```

| Cask | App |
|---|---|
| `bassjump-revived` | [BassJump Revived](https://github.com/09kleinkd/BassJumpRevived) — brings the Twelve South BassJump 2 subwoofer back to life on current macOS |

The app updates itself (Sparkle), so `brew upgrade` isn't needed for it.
